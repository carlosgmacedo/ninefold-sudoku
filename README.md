# Ninefold Sudoku

A SudokuPad-style sudoku player that works offline. It generates puzzles with exactly one solution, graded Easy to Expert by the logic techniques they require.

Play: https://carlosgmacedo.github.io/ninefold-sudoku/

On a phone, open the link, choose **Add to Home Screen**, and open it once while online. After that it works without a connection.

`src/` holds the editable source; `python3 src/build.py` rebuilds the site files into `src/dist/`.
